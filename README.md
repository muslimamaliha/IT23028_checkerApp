## Project Description
This project is a Django-based web application that detects vulnerabilities in NPM packages using the OSV API and a Machine Learning model. Users can enter a package name, and the system analyzes the package to provide its vulnerability risk score and severity level.

## Features
- Scan NPM packages
- Fetch vulnerability data from the OSV API
- Predict risk score using Machine Learning
- Display vulnerability severity
- Show CVE details and vulnerability summary
